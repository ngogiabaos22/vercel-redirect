# Flatsome UX Builder – trang Test IQ

`test-iq.txt` là nội dung trang https://tracnghiemaz.com/test-iq/ (page ID 189) viết bằng shortcode Flatsome.

## Cách dùng
1. Tải các ảnh trong `public/iq-test/png/` lên Thư viện media.
2. Thay mã giữ chỗ `IMG_...` trong `test-iq.txt` bằng ID ảnh tương ứng.
3. Dán toàn bộ nội dung vào trang (tab Văn bản / UX Builder) và cập nhật.
